# Akili Shambani — AI-Powered Phytosanitary Surveillance & Seed Verification

**Akili Shambani** is a localized AI platform combining Computer Vision (CNNs), Retrieval-Augmented Generation (RAG), and geographic anomaly detection to protect smallholder farmers in Kenya from invasive crop pests and counterfeit seeds.

## 🛠️ Technology Stack
* **Computer Vision:** PyTorch, MobileNetV3 / ResNet CNNs (Crop disease classification)
* **NLP & Vector Search:** LangChain, LlamaIndex, ChromaDB, Fine-tuned Llama/Mistral models
* **APIs & Gateway:** FastAPI, Python, WhatsApp Cloud API, USSD Gateway

## 📊 Core Benchmarks & Capabilities
* **Diagnostic Precision:** >92% top-1 accuracy on baseline crop pathology datasets (e.g., Fall Armyworm leaf damage).
* **Regulatory Grounding:** RAG framework indexing the *Plant Protection Act (Cap 324)* and KEPHIS certified seed registries.
* **Spatial Security:** Isolation Forest anomaly detection for location-tagged seed verification scans.

## 🚦 Project Status
Currently at the **Functional Prototype** stage, gearing up for sandbox trial deployment across the Nairobi-Murang’a-Nyeri agricultural corridor.
